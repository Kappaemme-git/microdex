# Microdex Support

Microdex is an independent, open-source companion for controlling a Codex
runtime on a user-owned Mac. It is not affiliated with or endorsed by OpenAI or
Work Louder.

## Get help

For pairing, setup, controls, privacy, or deletion requests, open a support
request in the public issue tracker:

https://github.com/Kappaemme-git/microdex/issues/new

Before opening a request, use **Settings → Copy diagnostics** in Microdex and
include the generated report when relevant. The report contains app, bridge,
and connection status, but never includes the bridge credential or end-to-end
encryption key.

Do not post pairing QR codes, decoded pairing URLs, OpenAI credentials, bridge
tokens, encryption keys, private task content, or other personal information in
a public issue.

## Security reports

Do not disclose a suspected vulnerability in a public issue. Use GitHub's
private vulnerability reporting for the repository instead:

https://github.com/Kappaemme-git/microdex/security/advisories/new

## Privacy

Microdex does not operate user accounts. Instructions for forgetting a paired
Mac, revoking all paired devices, removing the desktop bridge, and requesting
support are described in the privacy policy:

https://github.com/Kappaemme-git/microdex/blob/main/PRIVACY.md

Support is provided in English and Italian. Include the Microdex app version,
bridge version, iOS version, and macOS version so the request can be reproduced.
