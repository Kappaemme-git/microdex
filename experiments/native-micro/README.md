# Archived native-hardware experiment

This directory preserves an unsupported research experiment that presents a
synthetic HID device to a desktop client. It is not imported by the Microdex
bridge, included in the `microdex-cli` npm package, exposed by the CLI, or used
by the App Store app.

The experiment is retained only for source-history and compatibility research.
Its MIT notices must remain with any redistribution of this directory.
